# Schematic Labs

Schematic Labs was a San Francisco consumer music startup founded in 2010, best known as the maker of SoundTracking, an "Instagram for songs" mobile app for sharing the music you are listening to. Backed by Google Ventures (GV), Accel Partners, and SoftBank Capital, it was acquired by Rhapsody in August 2014 and wound down as a standalone company — soundtracking.com now redirects to napster.com and schematiclabs.com is a parked domain.

No public API or developer surface was found during enrichment. This profile records the company's place in the GV portfolio graph.
